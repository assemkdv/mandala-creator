# Symmetra

Symmetra is an interactive web app for creating beautiful, symmetrical mandala patterns in your browser.

## Live Demo

🔗 [Try it here](https://assemkdv.github.io/symmetra)

## Features

- Draw symmetrical mandala patterns in real time
- Adjustable brush size and color, plus a quick color palette
- Symmetry controls for different pattern styles
- Undo and redo (buttons or Ctrl+Z / Ctrl+Y)
- Download your mandala as a PNG

## Built With

- HTML
- CSS
- JavaScript (Canvas API)

## Getting Started

To run locally, simply clone the repo and open `index.html` in your browser:

```bash
git clone https://github.com/assemkdv/symmetra.git
cd symmetra
open index.html
```
